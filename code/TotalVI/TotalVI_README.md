## Installation
TotalVI is implemented on top of the scvi-tools Python package. Please refer to its [official installation guide](https://docs.scvi-tools.org/en/stable/installation.html) for detailed installation instructions.

After installation, we provide an example of running TotalVI using the 208-M2 → 208-M1 experiment in the CITE-SLN-Gayoso dataset.

## Run model
You can run TotalVI following the detailed instructions provided in `run_TotalVI.ipynb`.
