## Installation
For instructions on installing the Liger package, please refer to its [official installation guide](https://welch-lab.github.io/liger/articles/installation.html).

After installation, we provide an example of running Liger using the 208-M2 → 208-M1 experiment in the CITE-SLN-Gayoso dataset. 

## Run model
You can run Liger following the detailed instructions provided in `run_Liger.r`.
