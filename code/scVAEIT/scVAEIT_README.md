## Installation
For instructions on installing the scVAEIT package, please refer to its [official GitHub repository](https://github.com/jaydu1/scVAEIT).

After installation, we provide an example of running scVAEIT using the 208-M2 → 208-M1 experiment in the CITE-SLN-Gayoso dataset. 

## Preprocess data
Please run `scVAEIT_preprocess.r` to preprocess the gene expression data.

## Run model
You can run scVAEIT following the detailed instructions provided in `run_scVAEIT.ipynb`.
