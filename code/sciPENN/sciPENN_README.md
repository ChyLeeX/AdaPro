## Installation
For instructions on installing the sciPENN package, please refer to its [official GitHub repository](https://github.com/jlakkis/sciPENN).

After installation, we provide an example of running sciPENN using the 208-M2 → 208-M1 experiment in the CITE-SLN-Gayoso dataset. 

## Run model
You can run sciPENN following the detailed instructions provided in `run_sciPENN.ipynb`.
