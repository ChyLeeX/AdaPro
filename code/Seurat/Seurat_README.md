## Installation
For instructions on installing the Seurat package, please refer to its [official installation guide](https://satijalab.org/seurat/articles/install_v5).

After installation, we provide an example of running Seurat using the 208-M2 → 208-M1 experiment in the CITE-SLN-Gayoso dataset.

## Run model
You can run Seurat following the detailed instructions provided in `run_Seurat.r`.
